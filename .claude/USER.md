# USER — the owner

Shared, cross-specialist file for user-shaped knowledge about the owner: how they work, how
they decide, what they already know. Every specialist reads it; none owns it.

What routes here: the owner's role, responsibilities, preferences about collaboration, and
pointers to anything user-shaped kept elsewhere (rule 2 — one file per idea, point at the
original). What does not: a specialist's *own* lessons about working with the owner — those
are `feedback` memories in that specialist's lane.
