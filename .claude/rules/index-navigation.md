# index navigation

Indices are **standard** and one can be found in **every directory** (`CLAUDE.md`, `INDEX.md`, or `MEMORY.md`).
  - Indices are the **primary mode of navigation** for `~/workspace/`.
  - **An index row points; it never answers.** Every row carries a path, and says only enough to decide whether to open it.
  - **Use the index to navigate, not to learn**. If you want to learn, open the path and read the file.
