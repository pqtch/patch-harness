# Weekly review

1. Read the past week's entries under `_ops/journal/`.
2. For each open `para/projects/*/CONTEXT.md`, check "Current state" still matches
   what the journal shows; overwrite it if not (don't append history).
3. If you notice drift — stale memory entries, unused skills, index mismatches — run
   `/curate`.
4. Set the next week's top 3 priorities and note them in today's journal entry.
