# Projects

Active work. One folder per project, `para/projects/<kebab-case-name>/CONTEXT.md` inside.

## CONTEXT.md contract
- **What it is** — a sentence or two, stable, rarely edited.
- **Current state** — where things stand right now, overwritten as it changes, not
  appended to. This is not a log.
- **Pointers** — links to the actual work (code repos, docs, related projects),
  not copies of it.

No status archaeology: don't keep old "as of" entries around in CONTEXT.md. History
belongs in `_ops/journal/`; CONTEXT.md always reflects *now*.

When a project closes, move its folder to `para/archive/`.
