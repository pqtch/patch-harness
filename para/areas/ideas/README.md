# Ideas

Capture tiers, loosest to firmest:

- **seed** — a one-line thought, not yet worth more than that.
- **scaffold** — a seed someone came back to: rough shape, open questions listed.
- **ready** — scaffolded enough to become a `para/projects/` entry; next step is to
  make the folder and CONTEXT.md.

Keep entries as a flat list under a tier heading; promote by moving the line up, don't
duplicate it. When an idea becomes a project, remove it from here.
