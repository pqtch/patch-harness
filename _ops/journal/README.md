# Journal

Dated session logs: `_ops/journal/YYYY-MM/YYYY-MM-DD.md`, one file per day worked.

Each entry is what happened that session — decisions, what changed, what the next
session should pick up. This is where status and history live; it's not read every
session by default, only the newest entry (per `CLAUDE.md` session startup) plus
whatever the current work needs.

Session carryover — the thing the next session needs to know first — goes at the top
of the day's entry, not buried at the end.
