# Plans

Written plan documents for non-trivial work: `_ops/plans/<kebab-case-name>.md`, using
the schema in `.claude/skills/planning/SKILL.md` (goal, ordered tasks, STOP conditions,
out of scope).

Keep `INDEX.md` in this folder up to date: one line per plan, name + one-line status
(active / done / abandoned). When a plan finishes or is abandoned, update the index
rather than deleting the plan file — move closed plans' folders to `para/archive/` if
the plan document itself is no longer useful to reference.
